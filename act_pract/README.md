## Qué hay acá

10 programas independientes que cubren variables, tipos de datos, `input()`, conversión de tipos, operadores aritméticos/relacionales/lógicos, división entera y módulo, y f-strings. Todavía sin `if`, bucles, listas ni funciones propias, como pide el enunciado.

1. `programa_01.py` - Ficha personal
2. `programa_02.py` - Presupuesto de una compra
3. `programa_03.py` - Conversor de temperatura
4. `programa_04.py` - Conversor de tiempo
5. `programa_05.py` - Nómina básica de un trabajador
6. `programa_06.py` - Operaciones con dos números
7. `programa_07.py` - Datos de un rectángulo
8. `programa_08.py` - Reparto de entradas
9. `programa_09.py` - Comparador lógico de acceso
10. `programa_10.py` - Ticket de una tienda informática

## Cómo ejecutarlos

Necesitás Python instalado. Desde una terminal, parado en esta carpeta (`act_pract`), corré:

```
python programa_01.py
```

Y así con cada uno, cambiando el número. Cada programa va a ir pidiendo los datos por consola (nombre, edad, precios, etc.), los tenés que ir tipeando y apretando Enter después de cada uno.

Si `python` no te anda, probá con `python3`.
